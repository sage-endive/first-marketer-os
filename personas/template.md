# Persona Template

> **What this file is**
> A persona defines an AI role you invoke by name in Claude.ai Projects or Claude Code. When invoked, Claude adopts this role's behaviour, tone, focus, and constraints for the duration of that interaction.
>
> Copy this template to create a new persona. Be specific — vague personas produce vague behaviour.
